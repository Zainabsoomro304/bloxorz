Computer Graphics Project

Bloxorz 3D

Three.js / WebGL puzzle game

Project overview

Playable puzzle, complete flow

8 official levels with verified par values
rolling cuboid with exact grid rules
fragile tiles, switches, bridges, teleport split mode
keyboard, touch, smooth third-person camera
saved progress and custom level editor
hint system based on shortest-path search

Core model

The puzzle state is discrete

state = x, z, orientation

orientation:
  standing    one occupied tile
  lying_x     two occupied tiles on x axis
  lying_z     two occupied tiles on z axis

occupied cells decide legal moves, falling,
switch activation, bridge changes, and winning.

Movement and transforms

Smooth motion follows exact rules

1. validate the next grid state
2. update the puzzle position and orientation
3. animate the mesh position
4. rotate the mesh with quaternion motion
5. snap back to the exact grid coordinate

This keeps gameplay precise while the 3D motion stays smooth.

Level mechanics

Rules on the board

normal tile      supports the block
fragile tile     breaks under a standing block
heavy switch     standing block only
soft switch      any occupied cell
bridge           toggled tile in the level graph
teleport         splits the block into two cubes
merge            joins two adjacent split cubes
goal             accepts only a standing full block

Each mechanic changes move validation.

Graphics pipeline

Course concepts in the scene

geometry          block, tiles, bridges, particles
model transform   position, rotation, scale
view transform    camera frame
projection        perspective screen mapping
rasterization     triangles to fragments
fragment shading  lights and materials
frame buffer      final canvas pixels

Rendering

Scene and visual feedback

PerspectiveCamera for 3D depth
MeshPhysicalMaterial for light-based surfaces
DirectionalLight, AmbientLight, shadows, fog
SMAA, bloom, and vignette postprocessing
dust, shatter, sparkles, and win particles
procedural audio for movement and switches
guarded path tracing integration with fallback

Interaction

One game state, multiple controls

keyboard controls for desktop
touch controls for mobile
smooth third-person follow camera
HUD for moves, par, level, and hints
localStorage for progress and best moves

Solver

BFS over puzzle states

Breadth-first search explores moves level by level.
The first solution found is the shortest path.

state key:
  x, z, orientation
  bridge state
  split-block state

Used for:
  hint direction
  par verification
  solvability checks
